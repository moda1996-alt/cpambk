# 🏢 موقع محمود الباز قابيل — محاسب ومراجع قانوني وخبير ضرائب

موقع مؤسسي متكامل متعدد الصفحات بتصميم احترافي (كحلي + رمادي + أبيض) مع لوحة تحكم كاملة لإدارة المقالات.

## ⚡ التقنيات المستخدمة

- **HTML5** — هيكل دلالي (Semantic) متوافق مع محركات البحث SEO
- **CSS3** — تصميم متجاوب بالكامل مع حركات متقدمة (بدون أي مكتبات)
- **Vanilla JavaScript ES2022** — بدون أي إطارات عمل = أقصى سرعة وتوافق

> ℹ️ الموقع لا يستخدم أي صور أو لوجوهات خارجية — كل العناصر البصرية مبنية بـ CSS.

## 📁 هيكل المشروع

| الملف | الوظيفة |
|-------|---------|
| `index.html` | الصفحة الرئيسية |
| `services.html` | صفحة الخدمات |
| `about.html` | من نحن |
| `articles.html` | المقالات (ديناميكي) |
| `contact.html` | التواصل |
| `admin.html` | لوحة التحكم |
| `style.css` | تصميم الموقع |
| `admin.css` | تصميم لوحة التحكم |
| `main.js` | منطق الموقع |
| `admin.js` | منطق لوحة التحكم |

## 🚀 خطوات الرفع على GitHub Pages

1. أنشئ **Repository جديد** (Public) على github.com
2. ارفع الملفات العشرة في **جذر المشروع مباشرة**
3. فعّل GitHub Pages: **Settings → Pages → Branch: main → / (root) → Save**
4. موقعك يعمل خلال دقيقة على: `https://USERNAME.github.io/REPO-NAME/`

## 🔐 لوحة التحكم

| العنصر | القيمة |
|--------|--------|
| زر الدخول | "دخول الإدارة" في الشريط العلوي أو أسفل الفوتر |
| اسم المستخدم | `admin` |
| كلمة المرور | `Aa@123456` |

### مميزات لوحة التحكم:
- ✅ إحصائيات فورية (إجمالي المقالات، المنشور، المسودات، التصنيفات)
- ✅ نشر مقال جديد (عنوان، مقتطف، محتوى، تصنيف، حالة، تاريخ)
- ✅ تعديل وحذف ومعاينة المقالات
- ✅ المقالات المنشورة تظهر فوراً في الموقع

## ⚠️ ملاحظة أمنية

تسجيل الدخول يعمل عبر JavaScript في المتصفح (لأن GitHub Pages خدمة استضافة ثابتة بدون سيرفر). هذا مناسب للعرض والتجربة، لكنه **ليس حماية حقيقية**. للأمان الفعلي ستحتاج خدمة خلفية مثل Firebase Auth.
